### 1.2 命令真名对照表（🚨 虚构命令警示 · 全书统一）

| ❌ 虚构（不存在） | ✅ 真名 | 说明 |
|---|---|---|
| `openclaw init` | `openclaw setup`（或 `onboard`） | 无 `init` 子命令 |
| `openclaw agents create X` | `openclaw agents add X --workspace <dir>` | 是 `add` 不是 `create` |
| `openclaw chat --agent X --prompt Y` | `openclaw agent --agent X --message Y` | 是 `agent` 不是 `chat`；是 `--message` 不是 `--prompt` |
| `openclaw agents health-check` | `openclaw health` / `openclaw doctor` | 无 `health-check` 子命令 |
| `openclaw agents archive` | `openclaw backup create` | 归档走 backup |
| `openclaw plugin`（单数） | `openclaw plugins`（复数） | 复数 |
| `manifest.yaml` | `openclaw.plugin.json`（**JSON5**） | 不是 YAML |
| `~/.openclaw/workspace/openclaw.json` | `~/.openclaw/openclaw.json` | 主配置真身 |
| `openclaw cron add --schedule X --target Y --prompt Z` | `openclaw cron add --cron X --session Y --message Z` | 参数名不同 |
