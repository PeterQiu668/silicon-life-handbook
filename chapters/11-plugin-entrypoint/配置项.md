# 第 12 章 · Plugin 配置项（openclaw.plugin.json#configSchema 全表）

> **v5.0 行业标准版 banner**：本章对应 OpenClaw 训练学第 11 章（工程接口层 4/4）；详见 [README](./README.md)。
> **License banner**：MIT（基于 OpenClaw 主仓 LICENSE 法律文本）。
> **OpenClaw 真名**：`configSchema` 是 `openclaw.plugin.json` 唯一必填字段；硬要求 `{type: "object", additionalProperties: false}`。
> **业界对位**：本章对应 OpenClaw plugin configSchema（⚡领先） + uiHints（⚡领先）。

---

## 概述

plugin 的所有配置都通过 `openclaw.plugin.json` 的 `configSchema` 字段声明（**JSON Schema 7 子集**），用户在 `~/.openclaw/openclaw.json` 的 `plugins.entries.<id>.config.<key>` 写入实际值。本表覆盖 v5.0 行业标准版硅基生命训练学 plugin 的全部 13 个配置项 + 13 个 uiHints 表单 hint + 5 个枚举值约束。

**真名勘误**：
- ✅ 真名是 **`configSchema`**（不是 `config_schema` / `configuration` / `settings`）
- ✅ JSON Schema 硬要求 `{type: "object", additionalProperties: false}`（memory-lancedb / feishu / lobster / device-pair / open-prose 五个 stock plugin 一致）
- ⚠ 配置写入：`openclaw config set plugins.entries.silicon-life-training.config.paradigm "proactive-evolution"`
- ⚠ 配置 patch：`openclaw config patch`（支持 JSON5 注释保留；详见 docs.openclaw.ai/cli/config）
- ⚠ `--strict-json` 模式会拒绝 JSON5 注释——`configSchema` 本身只接受 JSON Schema 标准 JSON，但 `openclaw.json` 顶层可用 JSON5

## CLI 写入命令（4 种方式）

### 方式 1 · 单值写入（推荐）

```bash
# 写入字符串
openclaw config set plugins.entries.silicon-life-training.config.paradigm "proactive-evolution"

# 写入布尔
openclaw config set plugins.entries.silicon-life-training.config.ooda.autonomousGoalGeneration true

# 写入数字
openclaw config set plugins.entries.silicon-life-training.config.mentor.maxIterations 7
```

### 方式 2 · JSON5 patch（保留注释）

```bash
# 把 JSON5 patch 从 stdin 喂入
cat > /tmp/silicon-life.patch <<'EOF'
{
  // patch 1：提高信任分阈值
  "plugins.entries.silicon-life-training.config.governance.trustScoreThreshold": 85,
  // patch 2：开启自主目标（⚠ 高风险）
  "plugins.entries.silicon-life-training.config.ooda.autonomousGoalGeneration": true,
}
EOF

openclaw config patch --stdin < /tmp/silicon-life.patch
```

### 方式 3 · 完整重写

```bash
# 直接编辑 ~/.openclaw/openclaw.json（Gateway 监听热加载）
code ~/.openclaw/openclaw.json     # VS Code
vim ~/.openclaw/openclaw.json
```

### 方式 4 · 强制 strict JSON

```bash
# 拒绝 JSON5 注释/尾逗号/未引号 key（CI 用）
openclaw config set plugins.entries.silicon-life-training.config.paradigm "proactive-evolution" --strict-json
```

> **⚠ 真名警告**：docs.openclaw.ai/cli/config 原文："OpenClaw-owned writes that change config reserialize JSON5 as standard JSON. When the source contains comments, the writer warns immediately before removing them"——**用 `config set` 写值会把带注释的 JSON5 改写为标准 JSON；想保留注释请用 `config patch` 或手编**。

## schema 校验 + 运行时校验

### 设计期校验（CI 用）

```bash
# 校验 schema 本身合法（JSON Schema 7 子集）
openclaw plugins validate --root ./silicon-life-training --entry ./dist/index.js

# 校验配置值符合 schema
openclaw config validate ~/.openclaw/openclaw.json

# 取单个 schema 子节点（drill-down）
openclaw config schema.lookup plugins.entries.silicon-life-training.config.paradigm
```

### 运行期校验（Gateway 自动）

Gateway 启动时和每次热加载配置时，会自动做：
1. `JSON Schema` 校验（拒绝不符合 schema 的字段）
2. `enum` 校验（拒绝枚举外值，如把 `proactiveness` 写成 `"foo"` 直接报错）
3. `additionalProperties: false` 强制（拒绝未知字段）

校验失败行为：Gateway 拒绝加载该 plugin 并把错误写入 `~/.openclaw/logs/gateway.log`。
