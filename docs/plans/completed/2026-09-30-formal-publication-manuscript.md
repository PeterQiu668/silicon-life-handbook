# 正式出版版书稿生产计划

> 任务：以已确认的八卷二十四章为骨架，完成《训虾手册：硅基生命训练学——AI Agent 训练与人机协同最佳实践指南》的正式出版候选稿。
> 启动日期：2026-09-30
> 完成日期：2026-10-01
> 最终状态：`completed_as_formal_content_candidate`
> 主编原则：宁可分阶段完成，不以压缩篇幅或降低事实、实践、审校标准换取表面进度。

## 一、交付目标

正式交付不是单一长文件，而是一套互相校验的出版系统：

1. 八卷二十四章正式书稿，一章一文件；
2. 人类可连续阅读的合订主稿；
3. Agent 可渐进加载的机器入口与章节路由；
4. OpenClaw、Hermes、Muse 三平台实现映射；
5. 训练卡、任务卡、评测卡、交接卡、事故卡等可复用工具箱；
6. 来源、版本、事实类型与复核日期完整的证据账本；
7. 结构、链接、术语、引用、版本和章节合同自动校验；
8. 编辑审校、事实审校、实战试跑和出版前风险清单。

## 二、范围与非目标

### 本轮范围

- 保留并系统化“硅基生命”的人类仿生解读；
- 以跨框架训练原理为正文，以 OpenClaw 为主实现、Hermes 为第二开放实现、Muse 为托管产品与安全案例；
- 吸收初版、2026.9 行业版、v4/v5 探索中的原创方法和真实实践；
- 以截至 2026-09-30 的一手资料核验技术与协议事实；
- 每章完成方法、案例、失败模式、实战练习、产物和验收闭环。

### 暂不冒充已完成的事项

- 出版社终审、ISBN、印刷排版与发行；
- 未取得逐字稿的课程内容还原；
- 未实际运行的 30 天训练项目成果；
- 对闭源系统内部实现的无证据推断；
- “训完一定行业最强”等不可证伪承诺。

## 三、多 Agent 生产组织

### 角色

- 主编 Agent：唯一目录解释权、章际依赖、统一语言、最终并稿与验收；
- 历史材料主编：建立旧稿到 24 章的继承、重写、降级和淘汰映射；
- 平台与前沿研究主编：负责 OpenClaw、Hermes、Muse、MCP、A2A、Agent Skills、评测与安全证据；
- 出版质量总监：负责章节合同、语体、术语、案例、练习与质量门禁；
- 分章作者 Agent：一次只负责一章，不改他章和全局定义；
- 事实审校 Agent：核对版本性事实、一手来源和引用边界；
- 实战审校 Agent：检查步骤是否能执行、产物是否能验收、失败是否能恢复；
- 统稿审校 Agent：检查重复、矛盾、跳跃、语气和章际衔接。

### 文件所有权

- 一名分章作者只写指定章节文件；
- 研究 Agent 只写 `docs/research/`；
- 质量 Agent 只写 `docs/editorial/`；
- 只有主编修改目录、manifest、合订稿、状态、决策和执行日志；
- 所有旧稿均为只读取材源，不覆盖、不删除、不改名。

## 五、单章五道门

1. 初稿门：完整满足章节合同，不交提纲式文章；
2. 事实门：技术事实可追溯，版本事实带日期，推断与方法论明示；
3. 交叉门：无概念冲突、无无意义重复、输入输出能衔接；
4. 实战门：练习可执行，产物可检查，失败可停止或恢复；
5. 总编门：中文出版语体统一，人类顺读清楚，Agent 可渐进定位。

任何 P0 硬门槛失败，章节不得进入合订稿。

## 六、章节最低内容标准

- 普通章节建议 12,000—18,000 个中文字符；架构、安全、评测和训练营等高密度章节可达 16,000—24,000 个中文字符，但不得用重复和模板填充；
- 至少一个贯穿场景或可复现实例；
- 至少一个核心模型；
- 至少一套具体操作步骤；
- 至少三种失败模式；
- 至少一个实战练习和一个可提交产物；
- 明确通过、失败、需人工裁决的验收条件；
- 明确人类职责、Agent 职责、停止条件和升级条件；
- 含“硅基仿生镜头—工程真相—比喻边界”；
- 技术章节含 OpenClaw 主实现；适用处含 Hermes 对照和 Muse 案例；
- 关键主张进入来源账本，不以二手营销材料替代一手事实。

## 七、验证方法

- 结构：8 卷、24 章、三级节点和章节合同完整；
- 事实：抽查版本、命令、配置、协议和厂商能力；
- 链接：本地交叉链接和外部来源可达；
- 术语：同一概念只有一个主名称，别名首次出现时解释；
- 重复：相邻与跨卷内容重复扫描后由主编判断；
- 实践：每卷至少抽取一项练习试跑；
- Agent 可读性：用任务路由抽样验证能否只加载必要章节；
- 出版可读性：从卷首问题到卷末产物形成连续成长线。

## 九、风险控制

- 上游变化：正文只写稳定原理，版本事实进入实现框和附录；
- 多 Agent 文风分裂：以统一章节合同、术语表和主编统稿解决；
- 旧稿堆砌：必须按保留、重写、降级、淘汰重新判断；
- 引用失真：关键主张优先一手来源，单源事实标记局限；
- 仿生过度：所有生命隐喻都必须说明工程对应和比喻边界；
- 实践空泛：每章必须产生真实可检查的工作产物；
- 内容过长：通过渐进披露和附录分层解决，不通过删减关键逻辑解决。
