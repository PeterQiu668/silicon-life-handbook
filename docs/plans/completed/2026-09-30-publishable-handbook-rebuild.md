# 《训虾手册》出版级重构执行计划

## 目标

把现有“内容丰富但入口分散”的 v2026.9 行业标准版，重构为一套同时适合人类连续阅读与 Agent 渐进读取的正式手册。保留原有探索与深度资料，不通过删除或大规模搬迁制造信息损失。

## 本次范围

- 建立全书唯一的人类入口、Agent 入口和机器可读书目清单。
- 形成一份连续叙事的出版主稿，覆盖三门参考课程、初版八卷和 v2026.9 工程资料的核心成果。
- 用 2026-09-30 可验证的一手来源校准 OpenClaw、MCP、A2A、Agent Skills、评测与安全治理。
- 把“行业最强”从口号改写为可测量的毕业标准与回归门禁。
- 建立版本、事实、推断、方法论和待验证项的证据分层。
- 建立自动校验脚本，检查正式书目、内部链接、章节闭环、版本基线与遗留措辞。

## 非目标

- 不删除、移动或改名旧版与现有深度章节。
- 不把未经实测的命令写成已验证事实。
- 不承诺任何 Agent 经训练后“必然行业最强”；只定义可比较、可复现、可回归的强者标准。
- 不在本轮制作排版 PDF、印刷封面或 ISBN 交付。
- 不替作者决定整本书的最终版权许可。

## 结构原则

1. **一本书，一条主线**：定义强者 → 建模 → 配置底座 → 训练 → 评测 → 运行 → 记忆 → 工具 → 协作 → 治理 → 进化 → 毕业。
2. **双读者，同一事实源**：人类读主稿；Agent 先读机器入口，再按任务加载章节和附录。
3. **正文讲原理和决策，附录承载命令与清单**：避免主稿退化为 API 堆栈。
4. **证据优先**：事实带来源与复核日期；方法论标明是作者体系；推断和待验证项显式分层。
5. **训练即评测驱动改进**：没有基线、测试集、留出集、回归门禁和真实任务证据，不称为训练完成。
6. **主动性以提案为默认形态**：Agent 可以主动发现和提案，但不可把“主动”偷换成“越权执行”。
7. **安全边界由系统执行**：人格文档不是权限系统；安全依赖认证、策略、审批、沙箱、隔离和审计。

## 验收标准

- [ ] 主稿从头到尾可连续阅读，不要求先读旧版或重建报告。
- [ ] 每章包含：目标、关键模型、落地步骤、失败模式、产物、验收、深读入口。
- [ ] 三门课程的三系统与 AI 原生协作思想被纳入主线，并标明来源边界。
- [ ] 初版八卷的核心探索在覆盖矩阵中都有明确去向。
- [ ] OpenClaw 稳定基线固定为 `v2026.9.6 / eb377ac`；前沿 tag 与稳定版分开。
- [ ] MCP 固定到 `2026-07-28`；A2A 固定到 `v1.0.1`；Agent Skills 标明按复核日 main 规范。
- [ ] 所有正式书目文件存在，内部相对链接 0 broken。
- [ ] 主稿不出现“必然行业最强”“业界唯一”等不可证宣传语。
- [ ] 自动校验通过，结果写入执行日志。

## 风险与处理

| 风险 | 处理 |
|---|---|
| 现有内容约 8.8 万行，直接线性合并会更加臃肿 | 采用“出版主稿 + 深度参考层 + 操作附录”三层结构 |
| 现有目录含归档 README、备份、脚本和重建报告 | 由 manifest 排除，不急于删除 |
| 版本事实快速变化 | 固定 edition baseline，另设 frontier watch，不把 main 当稳定事实 |
| 训练学术语过多、易形成内部黑话 | 中文主名优先，英文仅用于对位；每章不新增无必要术语 |
| “生命体”隐喻可能掩盖工程边界 | 每次拟人化后补系统解释与权限边界 |
| 版权状态不清 | 保留作者版权，第三方引用按来源标注；最终许可待作者确认 |
