# C02 独立实践门评审

## 1. 实践门结论

**实践门决定：`PASS`。C02 的 P0-07 可以关闭。章节仍保持 `drafting`，本结论不构成 `done`、`release_candidate` 或生产发布批准。**

本轮在无网络、无真实数据、无凭证、无外发、无生产写入的模拟环境中实际执行了两项练习：

- X-C02-01 完成混合请求分流、生产失败止损、训练候选、数据边界、双向门禁、污染检查、三种桌面分支和回滚记录；
- X-C02-02 使用 2 个训练样本、2 个回归样本、2 个未见留出样本和 1 个压力样本执行确定性本地检查，保留完整基线、候选结果、成本门、压力失败和回滚证据。

结果不是“候选已经可以上线”。X-C02-02 的核心六个合成样本达到练习预设条件，因此**练习执行结果为 `PASS`**；压力样本 P1 暴露了过度保守的质量失败，因此**候选生产发布仍为 `REVIEW_REQUIRED`**。活动版本在运行前后都保持 `baseline-v0`，`production_release_authorized: false`。这说明练习能够让失败显形，并正确区分“训练测试通过”与“获准进入生产”。

所有证据见 [runs/](runs/README.md)。该目录已显式标注 `SIMULATED-PRACTICE-RUN`，不得改写成真实平台、客户或线上效果。

## 2. 安全与隔离说明

| 边界 | 实际执行 |
| --- | --- |
| 数据 | 只使用人工合成材料 ID、来源标签与预期动作；没有真实品牌、客户、个人或财务数据 |
| 网络 | 未连接外网、浏览器、消息通道或业务 API |
| 凭证 | 未读取或创建密钥、Token、账号与身份材料 |
| 写入 | 只在 `manuscript/volume-01/C02-training-paradigm/review/runs/` 保存模拟运行材料 |

| 裁判分离 | 候选生成与发布批准分离；样本预期动作由清单冻结；候选无权改评分或删除失败 |

模拟规则运行不等于真实模型评测。它足以验证教材步骤、证据结构、失败分支和回滚能否被另一评审者执行，但不能证明某个 Agent 已形成稳定能力，也不能支持行业领先或统计稳定主张。

## 5. 首次执行失败与修复

第一次运行检查器时，TSV 末尾空行被误计成第八个样本，得到 `total=8`、`core=7` 和一条伪安全失败，断言随即停止，没有产生 `PASS`。

定位后只修改检查器的记录选择条件：所有统计均要求 `sample_id` 非空。没有改样本预期动作、候选输出、成本门或发布状态。第二次运行得到 7 条有效记录和预期门禁结果。两次尝试都写入 `X-C02-02-execution.log`。

这个缺陷证明运行器也属于评测系统，不能假定脚本天然正确。教材后续可把“输入格式空记录”纳入实践审稿的固定回归项；本轮已用脚本再次执行并通过。

质量标准要求 P0-07 具备基线、证据和客观验收，不允许以“感觉更好”宣布训练完成。本轮关闭依据如下：

| 证据完整 | `PASS` | 输入、环境、脚本、结果、日志和哈希均可定位 |

**决定：关闭 `P0-07`。** 关闭的是“本章练习是否已实际产生基线、留出、失败与回滚证据”这一出版实践门，不是对任何真实产品效果的确认。若日后把本章宣称升级为“真实 Agent 训练有效”，必须另行运行真实但授权、匿名化、可复现的案例，并重新进入证据、实践和安全评审。
