# C02 独立实践门模拟试跑

> 证据身份：`SIMULATED-PRACTICE-RUN`。本目录所有对象均为教学合成数据和纸面/本地沙箱行为，不是 OpenClaw、Hermes、Muse 或任何真实客户系统的线上结果。

## 安全边界

- 未读取真实客户、个人、财务、身份或凭证数据；
- 未连接外网、消息通道、生产数据库或业务 API；
- 未执行外发、资金、删除、身份变更或生产写入；
- 被测对象是两个人工构造的策略版本 `baseline-v0` 与 `candidate-v1`；
- “运行”表示用冻结规则对合成样本做可重复的本地判定，并由脚本核对完整性和门禁；
- 任何通过结论只说明教材流程可执行，不证明真实 Agent 能力提升。

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `X-C02-01-simulation.md` | 分流练习的场景、双闭环、三种桌面推演与裁决 |
| `X-C02-01-output.yaml` | X-C02-01 的机器可读练习产物 |
| `X-C02-02-environment.yaml` | 迁移测试环境、版本、权限、成本门和回滚状态 |
| `X-C02-02-samples.tsv` | 两个训练、两个回归、两个留出及一个压力样本的完整记录 |
| `run-transfer-check.sh` | 只读评分与门禁核对脚本，不调用外部服务、不改生产状态 |
| `X-C02-02-result.yaml` | 迁移测试结果、失败、限制与三态决定 |
| `X-C02-02-execution.log` | 实际执行脚本的标准输出记录 |

## 可复现命令

从书稿根目录运行：

```bash
bash manuscript/volume-01/C02-training-paradigm/review/runs/run-transfer-check.sh
```

成功退出只表示：输入完整、核心六样本的候选行为达到预设条件、压力失败被单列、生产发布仍为 false、活动版本恢复为基线。它不授权发布候选。
