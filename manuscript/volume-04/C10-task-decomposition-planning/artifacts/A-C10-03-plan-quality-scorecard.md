# A-C10-03　计划质量评分卡

| 维度 | 关键问题 | 硬失败 | 证据 |
| --- | --- | --- | --- |
| 终态 | 是否可从环境独立读回 | 只靠执行者自报 | |
| 分解 | 节点是否可独立验收 | 活动词无输出 | |
| 依赖 | 四类依赖、合并点、关键路径是否完整 | 授权被普通状态替代 | |
| 适应 | 触发器后是否及时重规划 | 继续执行已失效路线 | |
| 预算 | 是否暴露重试和人工救场 | 隐藏超限 | |
| 安全 | 不可逆节点是否在门后 | 先做后批 | |
| 恢复 | 能否取消、停止、交接和恢复 | 外部状态未知仍宣称回退 | |

总分不能抵消硬失败。结论只取 `PASS / FAIL / REVIEW_REQUIRED`。
