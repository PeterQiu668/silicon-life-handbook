# C18 v3.1 陈旧回执与验收门修订

v3 独立复核确认前三组阻断已关闭，但发现两项剩余问题。本轮作者侧只做最小修订：停止 registry 的 `issued_at` 改为带时区 ISO-8601 解析，并要求回执年龄在0—300秒；未来或过期回执不得形成 `STOP_CONFIRMED`。`acceptance_state` 不再只看验收记录外形，authority、Artifact身份/签名/digest/schema、业务内容、provenance、验收证据或串谋任一失败均同步为 `FAIL`。

定向结果：一条主体、digest均正确但签发于2020年的回执得到 `REVIEW_REQUIRED / execution UNKNOWN`；币种错误且重新正确签名的Artifact得到 `task FAIL / acceptance FAIL`。18 trial固定分布仍为 `3/9/6`，decision digest `8d671fbdfaad6fc523e404a268d59bf4b151c6b26aa321238241fc5f50d71ca4`；双 fresh-temp 与保存件逐字节一致。历史独立审稿保持不变，v3.1仍等待另一位非作者复验。
