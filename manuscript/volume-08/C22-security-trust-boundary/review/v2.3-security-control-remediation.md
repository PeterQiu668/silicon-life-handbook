# C19 v2.3 安全控制整改记录

## 整改边界

本轮由非原作者执行，只关闭 `v2.2-independent-fact-cross-review.md` 登记的九项 fail-open。历史独立审校与复现文件未改写；本记录不批准事实、交叉、实践、编辑、总编或发布候选门。真实 OpenClaw、Hermes、Muse、Gateway、OS sandbox、credential broker、egress、WORM audit 与生产事故恢复仍为 `REVIEW_REQUIRED`。

## 两条冻结事实链

独立 `frozen-security-authority.yaml` 现包含 session registry、test definition registry 和 test evidence registry，并继续承载 principal、identity、delegation、policy、approval、grant、SecretRef、egress、input、供应链、audit、incident 与 recovery 权威记录。runner 重算 canonical root 后必须命中代码内 pinned digest；scenario 无法通过同步改写 registry 并重封 digest 取得通过。

运行事实链现在为：`session authority → delegation → approval/grant → effect(action/object/scope/params/executor/time) → receipt/authoritative readback → terminal audit event → incident effect chain → recovery evidence/residual owner`。评测事实链为：`test_ref → frozen definition → task/trial/layer/security slice/shadow → verified test evidence`。scenario 中同名字段只是观察值，必须与冻结记录逐项一致。
