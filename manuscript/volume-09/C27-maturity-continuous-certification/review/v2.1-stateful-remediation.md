## 1. 整改结论

v2.1 将认证输入、可信时钟与授权根分离。Builder 生成完整 raw state 与独立的
`frozen-certification-authority.yaml`；runner 只接受固定
`authority_root_digest=sha256:783e016643cfaaca3c02fbcdc2b3fc5e82ea33394063cca3bc99f56b7080e7fe`。
每个场景的元数据和完整状态均由 authority registry 绑定，输入自报状态、场景名和
`expected` 均无裁决权。

七项阻断均已关闭：

1. `LIMITED` 证书到期后不能保持 live lifecycle；
2. lifecycle `kind/current` 必须符合固定转换表；
3. lifecycle event 不得晚于可信时钟或早于证书签发；
4. material change 必须解引用与 change/release/full payload 绑定的证据；
5. trial output evidence 的 `FAIL/REVOKED` 为不可补偿硬失败，`REVIEW_REQUIRED` 只产生 RR；
6. Artifact content digest 必须为完整 SHA-256，并从 task/release 重算；
7. signature content digest 必须为完整 SHA-256，并绑定 subject/scope/release/task/platform/model/tools/data/budget/risk/environment/expiry/exclusions。

## 2. 独立式负向回归

`run-certification-negative-regression.py` 实际执行 25 项攻击，其中包含独立审校的
七项原攻击以及 18 项近邻攻击。结果为 `25/25 matched`、`0 fail-open`；22 项状态攻击
得到 `FAIL`，可信时钟、authority root 字面篡改和 authority registry 重封三项得到
`SCHEMA_REJECT`。suite digest 为
`sha256:e08087e7344ea7c9f4358d43ba48fde1eb5299700497f4e4399bcc581ded0469`。

固定 57 trial 的结果为：

- decision：`PASS=3 / FAIL=51 / REVIEW_REQUIRED=3`；
- lifecycle：`ACTIVE=1 / LIMITED=1 / SUSPENDED=3 / REVOKED=51 / EXPIRED=1`；
- decision digest：`sha256:b1b84d54cf191c5617491f1d98a134e62e19761c09d9292dfc37c1fda60dfeb3`；
- 离线 real-world、real-certificate、external-effect 拒绝尝试各 `1`；成功真实签发和外部 effect 为 `0`。

authority、input、result、summary、negative result 五类文件逐字节一致，并与仓库保存件一致。
完整哈希见 `runs/v2.1-fresh-temp-reproduction.yaml`。
